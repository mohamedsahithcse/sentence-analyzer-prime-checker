# Sentence Analyzer and Prime Checker

## Project Description
A simple Python program that analyzes a sentence and checks whether a number is prime.

## Features
- Counts the total number of words.
- Finds the longest word.
- Reverses the given sentence.
- Checks whether a number is prime.

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Download the repository.
3. Open the terminal in the project folder.
4. Run the command:

   python main.py
